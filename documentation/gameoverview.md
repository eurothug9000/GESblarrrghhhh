# Game Overview

First person adventure game in 3d enviorments with interactable objects that feature unique text and interactions.

# Features

- Movement in a 3d space 
- 360 look around with camera
- Interactable objects including ones with animation
- Text boxes, menus and other UI elements
- Inventory system to track your progress 
- Audio including ambient noise and voice overs along with sound effects
- saving and loading
- Locks with keys
- pause menu
- settings
- Interactive switches/buttons (e.g. lights)
